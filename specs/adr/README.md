# Architecture Decision Records — ADR

Las decisiones abiertas están indexadas en [`../DECISIONS.md`](../DECISIONS.md). Cada decisión aprobada se materializa mediante un ADR versionado, con autor y fecha.

## Plantilla

```markdown
# ADR-NNN — Título

- Estado: PROPOSED / ACCEPTED / SUPERSEDED
- Fecha:
- Dueño de decisión:
- Afecta changes:

## Contexto y drivers

## Opciones consideradas

## Decisión y justificación

## Evidencia (tests, benchmarks, aprobación institucional)

## Consecuencias, compatibilidad y rollback

## Revisión futura
```

No crear ADR aceptados con opciones inventadas ni usar Open Questions para postergar decisiones que cambien requisitos verificables.
