# Archivo de specs anteriores

Este directorio conserva la estructura de especificaciones que estaba activa antes de la consolidación funcional del 2026-10-14. Incluye cambios de trabajo versionados y no versionados que estaban dentro de `specs/` al momento del traslado.

La fuente de verdad funcional activa está ahora en:

- [`01 — Entrada y configuración`](../../../specs/01-entrada-configuracion.md)
- [`02 — Ejecución científica en MareNostrum 5`](../../../specs/02-ejecucion-cientifica.md)
- [`03 — Seguimiento y resultados`](../../../specs/03-seguimiento-resultados.md)

El archivo es referencia histórica y no constituye un segundo árbol de requisitos activo. No se eliminaron código de producto, datos ni resultados científicos. El traslado se hizo conservando los contenidos del worktree; Git puede detectar los renombrados cuando se revise el diff con detección de renames.
