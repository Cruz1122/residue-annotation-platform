# Acceptance 0003 — Visor interactivo

**Estado:** PARTIAL / NOT RUN. La feature quedó conectada a artefactos PDB/mmCIF publicados por una run; el snapshot read-only autorizado y la frontera de upload local aceptan un mmCIF real de `structure_modeling`, y el visor autenticado ya fue ejercitado con ese archivo como upload asociado a una run temporal. Todavía no se publicó como `StageResult` local ni se ejecutó el benchmark o un E2E con mapping científico verificable.

| REQ | Comprobación | Estado | Evidencia |
| --- | --- | --- | --- |
| REQ-VIZ-001 | Cargar un PDB/mmCIF publicado por backend | PARTIAL | `ProteinViewer` sólo llama Mol* cuando una run contiene un artifact_id de estructura. El snapshot SFTP read-only descargó los siete archivos explícitos del manifest, incluido `data_p01130` de 569,213 bytes con SHA-256 `c704b2…cd45c5`; tras corregir el parser que elegía el primer `loop_` de metadata, `POST /api/v1/uploads` en el Compose real devolvió `201` con el mismo tamaño y hash para `p01130_model.cif`, y el test de backend pasa. El 2026-10-14 una sesión autenticada cargó ese upload asociado a una run temporal: el árbol AX mostró `Visor molecular Mol*`, cadena A y 860 residuos, y la captura visual mostró la estructura renderizada. El manifest también declara `msa_cache_entry` como directorio externo en GPFS; el snapshot bounded no descarga directorios no acotados, por lo que el output completo aún no fue publicado como `StageResult` por el worker/API del checkout. |
| REQ-VIZ-002 | Selección de estructura y cadena/ins-code | PARTIAL (código + smoke browser) | El componente extrae cadena, auth residue e insertion code desde Mol*; el smoke autenticado mostró cadena A, seleccionó el primer residuo y abrió el panel `Anotaciones` con `MET 1`; falta E2E con múltiples cadenas/ins-code y mapping científico real |
| REQ-VIZ-003 | Mapping canónico honesto | PARTIAL (código) | La UI no deriva aa_position desde el número estructural y muestra posición canónica no disponible si no existe mapping |
| REQ-VIZ-004 | Estructura ausente/corrupta | PARTIAL (código + smoke browser) | El runtime Compose mostró `Sin estructura publicada` para una run terminal sin artifact de estructura y mantuvo la secuencia canónica visible; falta prueba manual de fichero corrupto |
| REQ-VIZ-005 | Evaluación reproducible de librerías | NOT RUN | Mol* sigue siendo la integración elegida en el frontend, pero no se ha registrado benchmark comparable ni ADR de cierre |

Las fuentes estáticas de prueba y los datos simulados del producto fueron eliminados. La validación y el upload real no convierten el gate científico en PASS: falta una publicación autorizada como `StageResult`, mapping validado y benchmark; la captura del smoke browser es evidencia puntual, no un artefacto de benchmark reproducible.
