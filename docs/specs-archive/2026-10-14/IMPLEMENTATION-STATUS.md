## Gates que no se deben sobredeclarar

- El adapter offline y las fixtures de tests no son una integración con MN5.
- Que una run se cree o que un stage pase a ready no significa que exista resultado científico.
- Sin StageResult publicado, la UI muestra pendiente/ausencia/NA y no inventa valores.
- La correspondencia entre numeración estructural y aa_position canónica sólo se mostrará cuando un stage publique mapping validado.
- Los acceptance de 0007, 0009, 0010, 0012, 0013, 0014, 0015 y 0016 conservan NOT RUN, PARTIAL o bloqueos donde faltan baseline, autorización, integración remota, proveedor externo o evidencia independiente.
